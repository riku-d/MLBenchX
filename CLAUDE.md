# ML-BenchX

Transparent AutoML for tabular data. Upload → profile → review and override the
preprocessing plan → execute → see every transformation explained → download artifacts.

Phase 1 source of truth: [docs/PHASE1_SPEC.md](docs/PHASE1_SPEC.md); status:
[AUDIT.md](AUDIT.md).

Verification evidence — commands run, results, coverage, timings, known limitations —
is in [VERIFICATION.md](VERIFICATION.md).

## Layout

```
backend/
  app/
    config.py        every threshold and seed, in one place
    pipeline.py      the plan: per-column actions, user-editable
    codegen.py       plan -> runnable Python
    executor.py      sandboxed execution of user-edited code
    workspace.py     interactive workspace routes
    main.py          dataset and run routes
    db.py            SQLAlchemy 2.x models
    storage.py       StorageBackend + LocalStorage
    services/        ingest, profile, health, impact, screening, target, glassbox
  migrations/        Alembic
  tests/             pytest, fixtures generated by tests/fixtures/generate.py
frontend/
  src/               React + Vite + TypeScript
```

## Running

```bash
cd backend && ../.venv/bin/python -m uvicorn app.main:app --reload --port 8000
cd frontend && npm run dev
```

## Conventions

- All thresholds and seeds live in `backend/app/config.py`. A number that appears twice
  will eventually disagree with itself.
- Type hints on all Python.
- Dependency versions pinned.
- The train/test split happens before anything is measured or decided — not only before
  fitting. See `docs/PHASE1_SPEC.md` §4 and `backend/tests/test_leakage.py`.
- No stubs, TODOs or mocked results. If something cannot be done, it is stated rather
  than faked.
